# Darwin v0.1 Architecture

Darwin v0.1 is a modular monolith with one deterministic supplied-material orchestrator. The repository is organized around small service modules for configuration, persistence, acquisition, source content, claim construction, validation, synthesis, and CLI access.

## Active Boundaries

- PostgreSQL is the intended persistent store.
- SQLAlchemy models and Alembic migrations define the durable data model.
- External acquisition is controlled and provider-agnostic.
- Source content fetching creates snapshots and deterministic segments.
- Evidence extraction is explicit.
- Claim construction requires caller-supplied claim text and selected evidence.
- Claim validation is structural and deterministic.
- Structured synthesis is evidence-grounded and append-only.
- Human validation is exceptional and explicit.

## Not Present

Darwin v0.1 does not include autonomous research, multi-agent architecture, LLM claim generation, semantic contradiction detection, recommendations, embeddings, pgvector, a separate vector database, a graph database, browser automation, PDF extraction, OCR, scheduled research, automatic trading, or a web UI.
