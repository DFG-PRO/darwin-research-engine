# Claim Validation Method

Phase 1.8D adds deterministic structural claim validation. It does not determine truth, score source quality, infer semantics, call AI/LLMs, or calculate numeric confidence.

## Validation Philosophy

Darwin separates evidence, support, corroboration, contradiction, and truth:

- Evidence is a sourced research unit.
- Support is an explicit stored relationship between evidence and a claim.
- Corroboration requires supporting evidence from at least two independent source origins.
- Contradiction is an explicit stored relationship between evidence and a claim.
- Truth is not determined by this phase.

Repeated reporting from derived or republished sources does not automatically become independent corroboration.

## Validation States

- `UNASSESSED`: no validation evaluation has been performed.
- `INSUFFICIENT_EVIDENCE`: no qualifying support or contradiction exists, or only contextual evidence exists.
- `SUPPORTED`: at least one supporting evidence relationship exists, but fewer than two independent supporting source origins are present.
- `CORROBORATED`: supporting evidence exists from at least two independent source origins.
- `CONTESTED`: both supporting and contradicting evidence exist.
- `CONTRADICTED`: contradicting evidence exists and qualifying support is absent.
- `HUMAN_REVIEW_PENDING`: a human review request has been explicitly recorded.
- `HUMAN_VALIDATED`: a human validation event has been explicitly recorded.

`SUPPORTED` and `CORROBORATED` do not mean a claim is true.

## Deterministic Evaluation Rules

Evaluation priority:

1. Explicit human validation produces `HUMAN_VALIDATED`.
2. Explicit human review request produces `HUMAN_REVIEW_PENDING`.
3. Supporting and contradicting evidence together produce `CONTESTED`.
4. Contradicting evidence without support produces `CONTRADICTED`.
5. Supporting evidence from at least two independent source origins produces `CORROBORATED`.
6. Any supporting evidence below the corroboration threshold produces `SUPPORTED`.
7. Contextual evidence alone produces `INSUFFICIENT_EVIDENCE`.
8. No evidence produces `INSUFFICIENT_EVIDENCE`.

No numerical confidence value is generated by these rules.

## Source Independence Rules

Darwin distinguishes distinct source records from independent source origins.

Source independence is based only on explicit lineage:

- A source with no `origin_source_id` is treated as its own independent origin.
- A source with `origin_source_id` is counted under the origin source for independence.
- Derived and republished sources are representable through `source_lineage_type`.
- URL or domain differences alone do not establish independence.

Darwin does not automatically discover source lineage in Phase 1.8D.

## Contradiction Handling

Contradictory evidence is counted and preserved. It is never discarded because supporting evidence is present. If support and contradiction both exist, the result is `CONTESTED`.

## Human Review Semantics

Human review must be explicitly requested. A review request creates an auditable human validation event and the next validation evaluation records `HUMAN_REVIEW_PENDING`.

Human review pending is not equivalent to human validation.

## Human Validation Semantics

Human validation must be explicitly recorded. It creates an auditable event containing:

- claim identifier
- validation event type
- timestamp
- optional non-sensitive validator label
- optional note

Human validation is never inferred from evidence counts.

## Reason Codes

Current reason codes:

- `NO_EVIDENCE`
- `SINGLE_SUPPORTING_SOURCE`
- `MULTIPLE_INDEPENDENT_SUPPORTING_SOURCES`
- `CONTRADICTORY_EVIDENCE_PRESENT`
- `ONLY_CONTRADICTING_EVIDENCE`
- `ONLY_CONTEXTUAL_EVIDENCE`
- `DERIVED_SOURCES_NOT_COUNTED_AS_INDEPENDENT`
- `HUMAN_REVIEW_REQUIRED`
- `HUMAN_VALIDATION_PRESENT`

Reason codes are persisted with each validation evaluation.

## Method Versioning

Each validation evaluation records `validation_method_version`. The default method version is `claim-validation-1.8d`.

## Known Limitations

- No semantic contradiction detection.
- No source reputation or independence inference.
- No numeric confidence scoring.
- No human workflow beyond explicit request/validation events.
- No source fetching, evidence extraction, claim generation, synthesis, recommendations, or memory retrieval.
